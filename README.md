## Homebrew (macOS)

```sh
brew install --cask syllogismos/tap/nimbus
```

On Homebrew 7+, you can also add the official tap and trust this cask once, then use the short name:

```sh
brew tap syllogismos/tap
brew trust --cask syllogismos/tap/nimbus
brew install --cask nimbus
```

Requires an Apple Silicon Mac running macOS 13 or later. [Homebrew tap](https://github.com/syllogismos/homebrew-tap).
